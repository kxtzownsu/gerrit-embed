# gerrit-embed
Adds an embed for changes on a specific Gerrit Code Review instance

>[!IMPORTANT]
>The official instance, crrev.kxtz.dev, is not up yet.

## How to use
The official instance is hosted at [crrev.kxtz.dev](https://crrev.kxtz.dev) which uses [Chromium Code Review](https://chromium-review.googlesource.com) as its BASE_URL

The examples below use the official instance's URL as an example, but you can replace it with your instance URL.

When using an instance of `gerrit-embed`, all you need to do is `https://crrev.kxtz.dev/{change-id}`, which will show an embed for that change.
